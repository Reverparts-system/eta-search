อัปเดตข้อมูล Inventory

ลากไฟล์มาวางพร้อมกัน: Inventory report (Rever Auto และ Rever ComV) + ไฟล์ SAP และ Rmos ของวันเดียวกัน (ถ้ามี ใช้เทียบ 3 ระบบ) → ตรวจสรุปผล → เผยแพร่ขึ้นเว็บ
คลิกเพื่อเลือกไฟล์ หรือลากไฟล์มาวาง
Inventory report DD-MM-YYYY (Rever Auto).xlsx · (Rever ComV).xlsx · SAP .XLSX · Rmos .xlsx
ตั้งค่า Inventory Analysis (RAM)
Value ของ Damage scrapped (บาท)
รายการ DMG Scrap
ไฟล์รายการต้องมีหัวคอลัมน์ Material และ Physical count (with Vendor)
มีการแก้ค่า – จะเผยแพร่พร้อมไฟล์ข้อมูล หรือกดเผยแพร่เฉพาะการตั้งค่า
